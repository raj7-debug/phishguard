# PhishGuard 🛡️

**Identify the Threat. Protect the System.**

PhishGuard is an interactive, high-stakes web simulation designed to train users' instincts against sophisticated digital deception and phishing attacks. It provides tailored training tracks to help different vulnerable demographics recognize and defend against real-world cyber threats.

## Key Features
* **Interactive Simulation Tracks:** Tailored training paths designed for specific user groups:
  * **University Students:** Focuses on defending against fake university portal alerts, scholarship scams, and credential harvesting.
  * **Elderly Citizens:** Focuses on recognizing pension fraud, fake banking alerts, and HMRC tax scams.
* **Targeted Awareness:** Bridges the literature review and practical training gap by educating users on context-specific social engineering tactics.
* **Responsive Frontend UI:** Built with a clean, modern design for a seamless user experience across devices.

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
